# Chancellor approved assets

Place only approved, source-of-truth Chancellor identity assets in this folder.

## Required production assets

- `chancellor-approved-portrait.*` — approved Bevan Shelton future-persona portrait
- `chancellor-crest.*` — approved crest/logo
- `business-readiness-audit-r500.*` — campaign artwork derived from the approved portrait and crest

## Guardrail

If `chancellor-approved-portrait.*` is absent, do not use a generated or stock human face as The Chancellor. Use crest/logo-led creative until the approved portrait is supplied.
